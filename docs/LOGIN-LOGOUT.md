# Login และ Logout

เข้าเว็บไซต์แล้วจะเห็นหน้าเข้าสู่ระบบ ใช้ Username/Password เดิมทั้ง admin และ viewer ได้ บัญชี viewer ยังคงดูข้อมูลได้อย่างเดียว

ปุ่ม **ออกจากระบบ** อยู่ด้านบนของหน้าหลัก ใบเปรียบเทียบ และเครื่องโหลดตู้ เมื่อเปิดเครื่องมือภายในหน้าหลักจะใช้ปุ่มของหน้าหลัก ออกจากระบบแล้วแท็บอื่นที่เปิดเว็บเดียวกันจะกลับหน้า Login ด้วย การกด Back ไม่ให้เข้าข้อมูลเดิมโดยไม่เข้าสู่ระบบใหม่

ระบบออกเมื่อไม่มีการใช้งาน 30 นาที และให้เข้าสู่ระบบใหม่อย่างน้อยทุก 12 ชั่วโมง การดึงข้อมูลอัตโนมัติไม่ต่ออายุการใช้งาน การเปลี่ยนรหัส/สิทธิ์หรือปิดบัญชีทำให้ session เดิมใช้ต่อไม่ได้หลังเซิร์ฟเวอร์โหลดค่าบัญชีใหม่ รีสตาร์ตเว็บจะให้ทุกคนเข้าสู่ระบบใหม่

Session อยู่ในหน่วยความจำเซิร์ฟเวอร์และใช้ cookie แบบ HttpOnly/SameSite=Lax; production ใช้ Secure ผ่าน HTTPS ไม่มีรหัสผ่านหรือ session token ใน localStorage การออกจากระบบยกเลิก token ฝั่งเซิร์ฟเวอร์และลบ cookie บัญชีและข้อมูลธุรกิจไม่เปลี่ยน

เครื่องมือ API เดิมยังใช้ Basic credentials ได้ เบราว์เซอร์ใช้หน้า Login และ cookie เพื่อป้องกันรหัสที่เบราว์เซอร์เคยจำไว้ข้ามปุ่ม Logout เครื่องมือที่ปลอม User-Agent เป็นเบราว์เซอร์ให้ใช้ User-Agent ปกติของเครื่องมือ

การทดสอบ: 131/131 ชุดหลักผ่าน, รวม 21 กลุ่ม และเบราว์เซอร์ทดสอบรหัสผิด, deep link, admin/viewer, หลายแท็บ, Back และ Logout ทุกหน้า ผ่าน ตรวจเพิ่มเติม session หมดอายุ/ยกเลิก/เปลี่ยนบัญชี, ปฏิเสธคำสั่งจากเว็บอื่น และการกลับมาหลังเครือข่ายขัดข้อง ด่าน staging เพิ่มการตรวจหน้า Login จาก image จริงและทดสอบ cookie หลัง Logout ต้องใช้ซ้ำไม่ได้
