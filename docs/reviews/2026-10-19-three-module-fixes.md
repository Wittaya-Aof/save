# ผลแก้ไขทั้งสามโมดูล — 19 ตุลาคม 2026

แก้ตามข้อบกพร่องที่ยืนยันจากรีวิว 24 ข้อ คงรูปแบบข้อมูลเดิมและสิทธิ์ Viewer โดยไม่เขียนทับข้อมูลประวัติอัตโนมัติ

| รหัส | สิ่งที่แก้ |
|---|---|
| L1 | แบ่งส่งแล้วหักยอดจาก shipment หลัก เก็บยอด PO เดิม ไม่รวมซ้ำ พร้อมเตือนเมื่อแบ่งเกินหรือคำนวณไม่ได้ |
| L2 | FX ที่ขาดเป็นข้อมูลไม่ครบ แทนเรท 1 หรือค่าประมาณ ทั้งหน้าเว็บ Dashboard และ Excel |
| L3 | แยกอัตราแลกเปลี่ยนตามบริษัท |
| L4 | ใช้เรทที่มีผลแล้ว ไม่ใช้เรทอนาคต เลือกเรทบริษัทก่อนเรทส่วนกลาง |
| L5 | สถานะนำเข้าและสถานะเก่าอยู่ในคอลัมน์ที่รองรับ |
| L6 | ตรวจบริษัท บอร์ด และตัวตน PO ก่อนใช้ข้อมูลที่บันทึกไว้ |
| L7 | ผลดึงบิลที่มาช้าไม่เปลี่ยนหน้าที่เปิดอยู่ ตรวจบริษัทของบิลก่อนใช้ |
| L8 | ETA กับการรับบางส่วนของ PO ไม่ถือเป็นหลักฐานว่ารับ shipment นั้นแล้ว |
| L9 | ใช้ผลบันทึกสถานะที่ยืนยันแล้ว ตรวจหลักฐาน Odoo ทั้งการลากการ์ดและแบบฟอร์ม |
| L10 | เลขแบ่ง shipment ใหม่ไม่ซ้ำหลังลบบางเที่ยว |
| L11 | บิลรวมหลาย PO แทนยอดประมาณการที่เกี่ยวข้อง โดยเทียบเลขเต็มและบริษัท |
| C1 | กล่องชั้นบนต้องมีพื้นที่รองรับครบ ไม่ใช่เพียงแตะบางส่วน |
| C2 | จำนวนชิ้นกล่องสุดท้ายที่ไม่เต็มตรงกันในผลหลายตู้และ CI/PL |
| C3 | ใช้เพดานความสูง SKU ในการจัดและจัดใหม่บนพาเลท |
| C4 | ขนาดแรกใส่ไม่ได้ยังลองขนาดถัดไปที่เลือกไว้ หยุดเมื่อไม่มีความคืบหน้า |
| C5 | จำนวนถังที่คาดการณ์ใช้ทิศทางเดียวกับการจัดจริง |
| C6 | CSV รองรับจุลภาค อัญประกาศ บรรทัดใหม่ และ BOM รวมถึงไฟล์แบบเดิม |
| C7 | ปฏิเสธน้ำหนัก ขนาด จำนวนผิดรูปแบบหรือติดลบ ไม่ยืนยัน payload เมื่อน้ำหนักไม่ระบุ |
| F1 | PDF สกุลเงินไม่ตรงแถวจะแจ้งและไม่เติม รวมราคาขั้นบันได |
| F2 | ผลบันทึกหรือลบผูกกับใบที่ส่ง การแก้ระหว่างรอไม่สูญหาย ไม่เปิดใบเดิมซ้ำระหว่างรอ |
| F3 | ขั้นบันไดแก้บนสำเนาชั่วคราว ยกเลิกแล้วคงเดิม กดใช้จึงคำนวณใหม่ |
| F4 | ราคาต่อหน่วยใน Excel ใช้ขั้นที่คำนวณจริง |
| F5 | PDF เติมเฉพาะช่องว่าง ไม่ทับราคาปกติหรือขั้นบันไดที่มีแล้ว |
| F6 | ขาด FX หรือฐานปริมาณจะแจ้งว่ายังคำนวณไม่ได้ และไม่แนะนำตัวเลือกถูกที่สุด |

PO ชื่อซ้ำข้ามบริษัทหรือบอร์ดแสดงเหตุผลและให้อ่านอย่างเดียว เพราะพื้นที่เก็บข้อมูลเดิมยังใช้ชื่อ PO เป็นคีย์ วิธีนี้ป้องกันการแก้ผิดรายการโดยไม่ย้ายประวัติเดิม

ใบเปรียบเทียบที่ไม่ระบุบริษัทไม่เลือก FX บริษัทใดให้อัตโนมัติ ผู้ใช้ยังกรอกเรทที่ตรวจสอบแล้วได้ การรองรับเต็มพื้นที่เป็นกติกาแบบอนุรักษนิยมของโปรแกรม ไม่ครอบคลุมการรับรองความแข็งแรงวัสดุ

เพิ่มเทสเรียกฟังก์ชันจริงและเบราว์เซอร์ด้วยข้อมูลจำลอง พร้อมตรวจพื้นที่รองรับเต็มใน geometry/fuzz เดิม ทดสอบทั้งล็อกอิน สิทธิ์ Viewer การบันทึก การคำนวณ การส่งออก และสำรอง/กู้คืน ก่อนขั้นตอน CI → staging → production ที่ย้อนรุ่นได้
