# Container Loading Calculator — คู่มือใช้งาน

เครื่องมือคำนวณการบรรจุสินค้าเข้าตู้คอนเทนเนอร์และรถบรรทุก แบบไฟล์เดียว เปิดใน browser ได้ทันที
รองรับสินค้าแบรนด์ **Kiss My Body** และ **Skinoxy** (เลือกแล้วกรอกขนาดกล่องอัตโนมัติ)

---

## เริ่มใช้งาน

1. ดับเบิลคลิกเปิด `container-loading-calculator.html` ด้วย browser (Chrome / Edge)
2. ไม่ต้องติดตั้งอะไร ไม่ต้องต่อ internet หรือ server
3. ถ้าแก้ไฟล์แล้วไม่เห็นการเปลี่ยนแปลง กด **Ctrl + Shift + R** (hard reload) เพื่อล้าง cache

---

## ขั้นตอนใช้งาน (3 แท็บ)

### 1️⃣ แท็บ "สินค้า"
- กด **+ เพิ่มกลุ่ม** เพื่อสร้างกลุ่มสินค้า, **+ เพิ่มสินค้า** เพื่อเพิ่มแถวสินค้า
- กรอกในตารางได้โดยตรง: ชื่อ, ยาว/เส้นผ่าศก., กว้าง, สูง (หน่วย **ซม.**), น้ำหนัก, จำนวน, สี
- กดปุ่ม **⚙️ (ตั้งค่า)** ที่แถวสินค้าเพื่อเปิดป๊อปอัป:
  - **เลือกสินค้า (Kiss My Body / Skinoxy)** จาก dropdown → ระบบกรอกขนาดกล่อง (ยาว×กว้าง×สูง) ให้อัตโนมัติ (หรือเลือก "กรอกเอง")
  - เลือกชนิด: **กล่อง / ถุงใหญ่ / ถัง / ม้วน** (แต่ละชนิดมีภาพ preview เฉพาะ)
  - การตั้งค่าการหมุน (เอียงตามยาว/กว้าง/สูง), ข้อจำกัด (จำนวนชั้นสูงสุด, ความสูงสูงสุด, น้ำหนักรวมสูงสุด), การเรียงถังแบบหกเหลี่ยม (hex pack)
  - **การทำนาย** — ป๊อปอัป "ความจุสูงสุด" ว่าสินค้านี้ใส่ได้กี่ชิ้นใน 20' STANDARD และ 40' HIGH CUBE
- ติ๊ก **ใช้พาเลท** หากต้องการวางบนพาเลท (ค่าเริ่มต้น: **พาเลทมาตรฐาน 1200×1000**)
- กด **ถัดไป →** เพื่อไปเลือกตู้/รถ

### 2️⃣ แท็บ "ตู้คอนเทนเนอร์/รถบรรทุก"
- เริ่มต้น **ไม่มีตู้** — ต้องกด **+ เพิ่มตู้คอนเทนเนอร์** เพื่อเปิด picker แล้วเลือกเองทุกครั้ง
- **Picker** แสดง grid การ์ดชนิดตู้ + แผงรายละเอียดสเปก (ภาพใหญ่ + Inside L/W/H, Capacity, Tare Weight, Max Weight) + ปุ่ม Cancel/Select
  - มี 2 แท็บ: **🚪 ตู้คอนเทนเนอร์** และ **🚛 รถบรรทุก**
- **รายการตู้ที่เลือก** เป็นแถวแก้ไขได้: thumbnail + dropdown ชนิด + ความยาว/กว้าง/สูง + น้ำหนักสูงสุด + จำนวน + ปุ่มลบ
  - มิติ (L/W/H) และน้ำหนักสูงสุด **ถูกล็อกตายตัวตามชนิดตู้** — เปลี่ยนได้เฉพาะผ่าน dropdown เลือกชนิด แก้ได้แค่จำนวน
- เพิ่มได้หลายตู้พร้อมกันเพื่อเปรียบเทียบ
- กด **คำนวณ →**

### 3️⃣ แท็บ "ผลการบรรจุ"
แสดง dashboard ต่อหนึ่งตู้/รถ:
- **การ์ดสรุป** — รูปตู้/รถ, ชื่อ, จำนวนหน่วยที่ต้องใช้, น้ำหนัก/ปริมาตรรวม
- **การ์ดรายละเอียด** — ภาพ 3D การจัดเรียง + แถบเปอร์เซ็นต์ปริมาตร/น้ำหนัก
- **Donut chart** + ตารางแยกตามสินค้า: ชื่อ / แพ็คเกจ / **ตามกว้าง / ตามยาว / ชั้นซ้อน** / ปริมาตร / น้ำหนัก
- **🧊 มุมมอง 3D** — เปิดหน้าต่างหมุนดูภายในตู้ 360°
- **ปุ่มท้าย** — กลับ / ส่งออกเป็น PDF / คัดลอกคำขอ

## ตรรกะการคำนวณ & การแสดงผล 3D

- คำนวณแบบ **grid-stacking** (เรียงเป็นชั้น) — ลองทุกการหมุนของกล่อง เลือกแบบที่เหมาะ
- เมื่อใส่ของได้ครบ ระบบ **เคารพ orientation ตามที่ป้อน** (ถ้าใส่ได้ครบ) — ไม่ใช่ max packing เสมอ
- **ภาพ 3D สะท้อนจำนวนจริง** ที่กรอก รวมถึงชั้นบนสุดที่ไม่เต็ม (partial layer) — เติมไล่จากด้านในสุดออกด้านนอก
- ตาราง **ตามกว้าง / ตามยาว / ชั้นซ้อน** = การจัดวางจริงของจำนวนที่กรอก (ไม่ใช่ความจุสูงสุด)
- มุมมอง 3D เป็นแบบ **perspective** มุมต่ำ ด้านในสุดอยู่ซ้าย ถอยไปขวา — ลากเมาส์หมุน 360°, สกรอลล์ zoom, มีปุ่ม auto-rotate

## พาเลท

ติ๊ก "ใช้พาเลท" แล้วเลือกชนิด (ค่าเริ่มต้น = **มาตรฐาน 1200×1000**):

1. พาเลทมาตรฐาน (1200×1000) ← เริ่มต้น
2. พาเลทยุโรป (1200×800)
3. พาเลทเอเชีย (1100×1100)
4. พาเลทอเมริกา (1219×1016)
5. พาเลทกำหนดเอง

พาเลทจะถูกวาดเป็นชั้นใต้สินค้าในภาพ 3D และหักความสูงพาเลทออกจากความสูงที่บรรจุได้

## เคล็ดลับ

- **ส่งออก PDF**: ปุ่ม "ส่งออกเป็น PDF" เรียก print dialog ของ browser → เลือก "Save as PDF" (แท็บ/ปุ่มจะถูกซ่อนอัตโนมัติตอนพิมพ์)
- หน่วยมิติสินค้าเป็น **ซม.** เสมอ — ระบบแปลงเป็น มม. ให้อัตโนมัติเมื่อเทียบกับขนาดตู้
- สลับภาษา **ไทย / English** ได้ที่มุมขวาบน (ข้อมูลทั้งหมดแปลตามภาษา)

## ข้อจำกัด

- ไม่มีการบันทึกข้อมูล (state หายเมื่อปิด/refresh) — และเปิดใหม่จะเริ่มด้วยรายการตู้ว่างเสมอ
- การคำนวณเป็นแบบ grid-stacking ไม่ใช่ optimizer แบบ irregular packing
- ภาพ 3D แสดงเป็น block ตามชั้น (ฐานเต็ม + ชั้นบนบางส่วน) ไม่ใช่กล่องทีละใบ
- ช่อง "จำนวน" ของตู้ใช้แสดงผลเท่านั้น ยังไม่ถูกนำไปคูณกับผลการคำนวณ
