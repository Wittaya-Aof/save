# ชุดทดสอบ packer ของ Container Loading Calculator

ตรวจ **invariant ทางเรขาคณิต** ของ `packLayout()` โดยตรง ไม่ใช่ดูจากภาพ 3D
(บั๊กพาเลททับกันที่เจอ 2026-07-31 มองจากภาพเห็นแค่ "ดูแปลก" แต่วัดด้วย invariant เห็นชัดว่าทับกี่ mm)

ต้องมี **api-server รันอยู่ที่ port 3000** ก่อน (โหลดหน้า calculator จาก localhost)

```bash
node tests/pack-invariants.mjs      # 42 scenario ที่เขียนมือ ครอบทุกตู้ + ทุก path
node tests/pack-fuzz.mjs 3000       # สุ่ม 3000 เคส (มี seed ทำซ้ำได้)
```

## invariant ที่ตรวจ
1. ทุก block อยู่ในตู้ (x/y/z) และไม่มีขนาดติดลบ/ศูนย์
2. ไม่มี block ไหนทะลุกันใน 3 มิติ (รวม deck พาเลทกับกล่อง)
3. ไม่มีกล่องลอย — ต้องวางบนพื้น / บนหน้าพาเลท / บนกล่องอื่น
4. จำนวนกล่องที่วาดจริง (`nL×nW×nH`) = `stats.placed` และไม่เกินจำนวนที่สั่ง
5. `maxLayers` ที่ผู้ใช้ตั้งไว้ต้องไม่ถูกละเมิด
6. คอลัมน์ "ชั้น" ที่รายงาน ต้องไม่เกินจำนวนระดับ z ที่วาดจริง

## เคสที่ครอบ
ทุกตู้/รถทั้ง 10 แบบ · std / พาเลท / ผสม · พาเลทหลายสเปคในตู้เดียว · drum(hex)/roll/pipe ·
ห้ามหมุนกล่อง · maxLayers · maxH2 · กล่องใหญ่กว่าตู้ · qty=1 · ของล้นตู้

`pack-fuzz.mjs` ใช้ PRNG แบบมี seed (mulberry32) — เคสที่พังจะพิมพ์ `seed=N` ออกมา
ให้ทำซ้ำได้ พร้อมสเปคสินค้า/พาเลทของเคสนั้น
